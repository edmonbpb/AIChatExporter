# 📚 مستندات جامع مهندسی و بازسازی اپلیکیشن AIChatExporter

این پوشه حاوی پلن جامع و مهندسی معکوس صفر تا صد اپلیکیشن **AIChatExporter** است. این مستندات به نحوی مدون شده‌اند که هر ایجنت هوش مصنوعی، مهندس نرم‌افزار یا تیمی بتواند بدون هیچ‌گونه ابهام یا نیاز به فرضیات خارجی، کل پروژه را از ابتدا تا انتها بازسازی، تست و اجرا نماید.

### 🛠 ساخت و اجرای همین مخزن (۲۰۲۶-۱۰-۰۶)

```bash
cp .env.example .env         # سپس GEMINI_API_KEY و GOOGLE_CLIENT_ID را پر کنید
./gradlew :app:assembleDebug # خروجی: app/build/outputs/apk/debug/app-debug.apk
./gradlew :app:testDebugUnitTest
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

پیش‌نیازها: JDK ۱۷ یا بالاتر، Android SDK با پلتفرم ۳۶، و فایل `local.properties` شامل `sdk.dir=…`. برای امضای نسخهٔ ریلیز، متغیرهای محیطی `KEYSTORE_PATH`، `STORE_PASSWORD` و `KEY_PASSWORD` باید ستان شوند؛ اگر نباشند، ساخت نسخهٔ دیباگ باز هم کار می‌کند.

کلید امضای آپلود روی این ماشین ساخته شده است: `C:\Users\edmon\.qoder\secrets\aichatexporter-upload.jks` با نامِ کلید `upload` (رمزها در بخش `[android-signing]` همان پوشهٔ `accounts.ini`‌اند و هیچ‌جا نوشته نمی‌شوند). برای بستۀ **عمومی** این فرمان را بزن، تا کلید هوش مصنوعی داخلِ بسته نرود:

```
./gradlew :app:bundleRelease -PpublicBuild=true --no-configuration-cache
```

`--no-configuration-cache` اجباری است: افزونۀ رازها فهرستِ استثناها را در زمانِ پیکربندی عوض می‌کند و گرادِل این را در حافظۀ پیکربندی نمی‌بیند، پس یک اجرایِ عمومی می‌تواند کلیدِ build بعدی را بی‌صدا کم یا زیاد کند (ردیفِ B-34 در سند ۰۹). پس از هر بیلدِ عمومی، کلید را در dexهای خودِ بسته جست‌وجو کنید.

بدونِ این پرچم، بیلد کلید `GEMINI_API_KEY` را از `.env` برمی‌دارد و داخلِ dex می‌گذارد؛ شاهدِ این ادعا با جست‌وجوی بایتیِ کلید در dexهای خودِ بسته گرفته می‌شود.

تست‌های JVM به فایل `app/libs/json-20240303.jar` نیاز دارند (نسخهٔ واقعی `org.json`؛ پوستهٔ داخل jar ساختاندیِ اندروید فقط استثنا می‌دهد). این فایل در مخزن نگه داشته شده تا اجرای تست به شبکه نیاز پیدا نکند.

ورود با گوگل برای کارکردِ واقعی به ثبتِ این دو مقدار در کنسول گوگل نیاز دارد: نام بستهٔ برنامه و SHA-1 کلید امضا، به‌همراه کلاینت وبی که شناسه‌اش در `GOOGLE_CLIENT_ID` می‌نشیند. برای توسعه اثرانگشتِ `~/.android/debug.keystore` کافی است؛ برای نسخۀ ریلیز باید SHA-1 همان کلید آپلود هم به همان کلاینت Android افزوده شود، وگرنه صفحۀ ورود در بستۀ امضاشده می‌شکند. تا وقتی صفحۀ رضایت‌نامه در حالت Testing است، فقط حساب‌های دست‌چین و سقف ۱۰۰ کاربر در کل عمر برنامۀ اجازه ورود دارند.
